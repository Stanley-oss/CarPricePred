#主要设计理念：
  消除偏置，主干网络只关心基础价格，最后加回偏置
#三个核心方法处理偏置：
  1.log变换缓解长尾
  2.计算核心残差，除去了品牌和燃油类型溢价后的纯粹车价
  3.截断来自10%最离谱豪车的价钱
#主干网络：
  1.3层ResNet（感觉够用了）
  2.有待添加...
